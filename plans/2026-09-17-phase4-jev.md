# Fase 4 — Jev (System One) no harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Quatro usos do Jev no harness — health semântico (A), dedup (B), priorização (C) e segunda opinião no verify (D) — sobre um núcleo único `jev_ask` com opt-in, egress redigido, audit e teto de chamadas.

**Architecture:** `bin/hx` ganha o núcleo (`jev_config`, `jev_budget_take`, `jev_http`, `jev_ask`, `hx jev status`) em stdlib (`urllib.request`). A/B/C são fail-open (sem Jev, comportamento atual); D é fail-closed (sem veredito do Jev, promoção automática não acontece — caminho `--attest` humano). Nada sai sem `scope.json → jev.enabled` e `TYPESAFE_API_KEY`.

**Tech Stack:** Python 3 stdlib (urllib), API HTTP `POST https://api.typesafe.ai/v1/systemone` (Bearer), modelo `jev-latest`. Zero dependência nova.

**Spec:** `specs/2026-09-15-hunt-harness-design.md` §9.4 (Rev 11).

## Global Constraints

- `bin/hx`: arquivo único, stdlib-only, **zero comentários/docstrings**, mensagens PT (identificadores em inglês). `runner/runner.py` idem.
- Testes são locais: `tests/` é gitignored — nunca staged/committed. Commits tocam só `bin/hx`, `runner/runner.py`, `README.md`, `templates/*`.
- **Nenhum request de rede em teste**: o seam é `hx.jev_http(payload, key, timeout)` (monkeypatch); testes ligados ao Jev monkeypatcham `hx.jev_ask`.
- Egress: sem `jev.enabled` e sem key, `jev_ask` não faz request e não audita; payload passa por re-redação (`redact_body`) antes do POST.
- Fail modes: A/B/C fail-open com `jev: unavailable` no audit; D fail-closed (ver §9.4).
- Commits em PT, um por task.

```python
JEV_DEFAULTS = {
    "enabled": False,
    "model": "jev-latest",
    "max_calls_per_run": 50,
    "thresholds": {"health": 0.8, "dedup": 0.85, "verify_high": 0.8, "verify_low": 0.5},
}


def jev_config(scope):
    config = json.loads(json.dumps(JEV_DEFAULTS))
    provided = scope.get("jev") or {}
    for key, value in provided.items():
        if key == "thresholds" and isinstance(value, dict):
            config["thresholds"].update(value)
        else:
            config[key] = value
    return config


def jev_budget_take(repo, scope):
    run_id = os.environ.get("HX_RUN_ID") or f"hour-{int(now() // 3600)}"
    cap = int(jev_config(scope).get("max_calls_per_run") or 0)
    with flock(repo.hunt / ".lock.jev"):
        state = load_json(repo.hunt / ".jev.json", {})
        if state.get("bucket") != run_id:
            state = {"bucket": run_id, "calls": 0}
        if cap and state.get("calls", 0) >= cap:
            dump_json(repo.hunt / ".jev.json", state)
            return False
        state["calls"] = state.get("calls", 0) + 1
        dump_json(repo.hunt / ".jev.json", state)
        return True


def jev_http(payload, key, timeout=10):
    body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
    request = urllib.request.Request(
        "https://api.typesafe.ai/v1/systemone",
        data=body,
        headers={"Authorization": f"Bearer {key}", "Content-Type": "application/json"},
        method="POST",
    )
    try:
        with urllib.request.urlopen(request, timeout=timeout) as response:
            return response.status, json.loads(response.read().decode("utf-8"))
    except urllib.error.HTTPError as err:
        return err.code, {}
    except Exception:
        return None


def jev_ask(repo, scope, use, state, questions, threshold):
    config = jev_config(scope)
    if not config.get("enabled"):
        return None
    key = os.environ.get("TYPESAFE_API_KEY")
    if not key:
        audit(repo, "jev", use, "-", "unavailable", "sem TYPESAFE_API_KEY")
        return None
    if not jev_budget_take(repo, scope):
        audit(repo, "jev", use, "-", "cap", f"teto de {config.get('max_calls_per_run')} chamadas")
        return None
    try:
        redacted = json.loads(redact_body(json.dumps(state, ensure_ascii=False)))
    except Exception:
        audit(repo, "jev", use, "-", "unavailable", "state nao serializavel")
        return None
    payload = {"state": redacted, "model": config.get("model") or "jev-latest", "questions": questions}
    result = jev_http(payload, key)
    if not result or result[0] != 200 or not isinstance(result[1], dict):
        audit(repo, "jev", use, "-", "unavailable", f"http {result[0] if result else 'erro'}")
        return None
    answers = result[1].get("answers") or {}
    summary = json.dumps(answers, ensure_ascii=False)[:200]
    audit(repo, "jev", use, f"thr {threshold}", "allow", summary)
    return answers
```

```python
        }, jev_config(scope)["thresholds"]["dedup"])

            if chosen != "new" and probability >= jev_config(scope)["thresholds"]["dedup"] and not args.force:
                raise HxError(f"equivalente a {chosen} (p={probability:.2f}) — use --force para enfileirar", EXIT_GUARD)
            duplicate_of = chosen if chosen != "new" else None
        else:
            duplicate_of = None
    else:
        duplicate_of = None
```
